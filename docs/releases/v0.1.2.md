# v0.1.2 — First GitHub Packages release

Pilot application of the [`publish-packages` skill](https://github.com/tyroneross/RossLabs-AI-Toolkit/blob/main/skills/publish-packages/SKILL.md).

## What ships

- **`@tyroneross/pyramid-principle@0.1.2`** on GitHub Packages (`https://npm.pkg.github.com`).
- Per `package.json` `files:` whitelist: `.claude-plugin/`, `.codex-plugin/`, `skills/`, `docs/`, `README.md`, `LICENSE`.

## What changed

- New `package.json` with publish metadata only (no `dependencies` block — plugin remains pure Markdown + JSON).
- `.codex-plugin/plugin.json` bumped `0.1.1 → 0.1.2` to match `.claude-plugin/plugin.json`.
- `.github/workflows/publish-npm.yml` — release-triggered publish with tag-vs-manifest drift guard and inter-manifest drift guard (`package.json` / `.claude-plugin` / `.codex-plugin` must agree).
- `.github/workflows/verify-install.yml` — `workflow_run`-chained smoke test using the auto-provisioned `GITHUB_TOKEN`.

No skill content changes in this release — pure packaging.

## Install

The Claude Code marketplace install path is unchanged. The npm distribution adds a second channel for tooling that wants to pin to a specific version:

```bash
echo "@tyroneross:registry=https://npm.pkg.github.com" >> ~/.npmrc
echo "//npm.pkg.github.com/:_authToken=<PAT>" >> ~/.npmrc
npm install @tyroneross/pyramid-principle
```
